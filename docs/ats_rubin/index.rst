#########
Rubin ATS
#########

The Rubin Automatic Test System (ATS) is a hardware-in-the-loop environment for developing, testing, and training on the Telescope Mount Assembly (TMA).
It mirrors key summit control hardware with real-time PXI controllers, Speedgoat axis simulation, safety and encoder interfaces, supporting virtual machines, subsystem simulators, and automated tests.
It provides a controlled platform for validating changes and preparing operators without relying on the production system.
